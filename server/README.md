# Baby Craft 서버

방장 없이 **서버가 채널(방 번호)의 세상을 돌립니다.** 사람 기기는 모두 손님입니다.

```
사람 기기 (GitHub Pages, 손님)  ──┐
사람 기기 (GitHub Pages, 손님)  ──┼──  Firebase (주고받는 곳 + 세상 저장)  ──  서버 (이 컴퓨터, 채널마다 하나)
사람 기기 (GitHub Pages, 손님)  ──┘
```

- **서버가 하는 일**: 동물 움직이기, 맞은 동물 쓰러뜨리기, 동물/아이템/네잎클로버 다시 나기, 보스, 길들이기 판정.
- **세상 저장**: 채널마다 `rooms/{채널}/world` (시드, 보스 진행), `rooms/{채널}/t` (바뀐 맵 칸).
  - 서버가 꺼져도 남아서, 다시 켜면 이어서 돌립니다.
  - 채널에 세상이 없으면 채널 기본 맵으로 새로 만듭니다 (채널 번호마다 늘 같은 맵).
- **채널 주인은 없습니다.** 서버가 그 채널의 자리를 차지하고, 사람 기기는 서버가 켜질 때까지 "🖥️ 서버가 켜지길 기다리는 중…" 으로 기다립니다.
- 서버 프로그램은 게임과 같은 코드(`index.html?server=1111`)를 **화면 없는 크롬**으로 띄운 것입니다. 캐릭터 없이 세상만 돌리고, 그리지 않습니다.

## 켜기 (이 컴퓨터, Windows)

`server\start-server.bat` 을 더블클릭합니다. 창이 떠 있는 동안 서버가 돕니다 (창을 닫으면 꺼짐).

- 채널 여러 개: `server\start-server.bat -Channels 1111,2222`
- 기록: `server\logs\1111.log` (크롬 콘솔), `server\logs\web.log`
- 필요: Google Chrome, Python (게임 파일을 `127.0.0.1:8090` 에서만 보여 줍니다. 밖에서는 못 들어옵니다)
- 게임 코드를 바꿔서 `index.html` 의 `game.js?v=` 숫자가 커지면 서버가 30초 안에 알아서 새로 켜져 새 코드로 돕니다 (v82 부터. 그 전 버전 서버는 한 번 껐다 켜야 합니다)
- 컴퓨터가 잠자기에 들어가면 서버도 멈춥니다 (Windows 전원 설정에서 잠자기 끄기 권장).

## 유료 서버로 옮기기 (리눅스)

1. 서버에 레포를 받고 `python3`, `chromium` 을 설치합니다.
2. `./server/start-server.sh 1111` (항상 켜 두려면 systemd 서비스나 `tmux` 로).
3. 이 컴퓨터의 서버는 끕니다 (두 서버가 같은 채널을 켜면 나중에 켠 서버가 맡고, 먼저 켠 서버는 멈춥니다).

세상은 Firebase 에 있어서 옮길 것이 없습니다. 서버 컴퓨터만 바뀝니다.
