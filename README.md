# 🧱 Baby Craft

6살 아이를 위한 마인크래프트풍 2D 브라우저 게임입니다.
돌아다니며 재료를 줍고, 무기를 만들고, 몬스터를 물리칩니다.
중간중간(적 처치, 기절 후 집) **단어 카드**가 나오고, 소리 내어 읽으면 다음으로 진행됩니다.
그리고 놀고 있는 시간 **1분마다** "계속하려면 문장을 읽어요!" 하고 **📝 문장 카드**(띄어쓰기 빼고 8글자까지, 예: "엄마 아빠 사랑해요")가 나옵니다.

폰/태블릿에서는 ▶ 를 누르면 **전체 화면**이 됩니다 (아래 뒤로/홈 버튼이 숨겨짐). 실수로 빠져나가면 화면을 다시 누를 때 돌아옵니다. iPhone Safari 는 전체 화면을 지원하지 않으니 공유 → **홈 화면에 추가** 후 그 아이콘으로 여세요 (Android 도 이렇게 하면 처음부터 전체 화면).

- 순수 HTML + JavaScript + Canvas (빌드 없음, 정적 사이트)
- 음성 출력: `speechSynthesis` (ko-KR / en-US)
- 음성 인식: Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`)
- 대상: Chrome (PC, 안드로이드 태블릿)

> 진행 상황: **3단계 완료** (탐험 + 제작 + 전투 + 보스). 보스(🐉 용)도 다른 몬스터처럼 잡으면 단어 카드 한 장을 읽고 같은 맵에서 계속합니다.

## 저장

이 기기에 **내 세상**(맵 + 캐고 놓은 칸)과 **가방**(아이템, 무기, 잡은 몬스터 수)이 5초마다, 그리고 창을 닫거나 다른 앱으로 갈 때 저장됩니다. 다음에 ▶ 를 누르면 그 세상에서 이어서 합니다.

- **가방은 캐릭터 이름별로 서버(Firebase)에도 저장**된다. 다른 기기에서도 같은 이름으로 시작하면 그 가방으로 이어서 한다 (맵은 기기마다 따로)
  - 이 기기 가방이 그 이름 것이고 서버보다 나중에 바뀐 것이면 이 기기 것을 쓴다. 다른 이름으로 시작하면 그 이름의 가방(없으면 빈 가방)
  - 이름만 같으면 누구나 그 가방을 쓸 수 있다 (비밀번호 없음). 인터넷이 안 되면 이 기기 저장만 쓴다
- 시작 화면의 🌱: 새 세상. 한 번 누르면 ❗ 로 바뀌고, 3초 안에 한 번 더 눌러야 지워진다 (아이가 실수로 지우지 않게)
- 여럿이 하기: 🏠 방을 만든 사람은 **자기 세상 그대로** 방을 연다. 들어온 사람은 그 세상에서 놀고, 자기 가방만 저장된다 (자기 세상은 그대로)
- 따라다니는 동물(💕)도 저장된다
- 맵 만드는 방법이 바뀌면(예: 네 구역 지도) 예전에 캐고 놓은 칸은 새 맵에 맞지 않아서 버린다. 가방은 그대로
- 저장은 이 기기 브라우저(localStorage)에만. 브라우저 데이터를 지우면 사라진다

## 한 판의 흐름

0. 시작 화면에서 **캐릭터 이름**을 입력한다 (머리 위에 보인다. 이 기기에 저장되어 다음부터는 바로 ▶)
1. 돌아다니며 재료(🪵 🪨 🧵)와 음식(🍎 🥛 🍇 🥚)을 줍는다. 동물을 잡으면 고기, 가죽, 가시 같은 그 동물에 맞는 것이 나온다. ❤️ 하트를 주우면 체력이 2 찬다
   - 맵은 120x90칸. 오른쪽 위 **작은 지도**에 맵 전체, 지금 보이는 곳(흰 네모), 나(파랑), 다른 사람(빨강), 용(보라)이 보인다
   - **캐기**: 나무/꽃/바위를 바라보고 ✋ (옆칸에 흰 테두리가 보이면 캘 수 있음). 캔 자리는 풀밭이 되고 **다시 자라지 않는다** (맵 테두리 나무는 못 캔다)
     - 🌷 꽃: 한 번
     - 🌳 나무: 맨손 3번 / 🪓 도끼 1번. 🪵 통나무도 하나 더
     - 바위: 맨손 5번 / 🪓 도끼·🗡️ 칼 2번. 바위 블록과 🪨 돌(무기 재료) 하나가 나온다
     - **땅은 움직일 수 없다**: 풀밭(연두/초록/흑녹), 모래(황토), 흙 길, 호수(물)는 캐지 못하고 아이템도 안 나온다. 호수는 정해진 자리에 그대로. 예전에 땅을 캐고 놓아 바뀐 칸은 불러올 때 원래 맵대로 돌아간다
     - 놓았던 블록을 캐면 그 아래 원래 땅으로 돌아간다 (모래 위에 놓은 바위를 캐면 모래)
     - 캔 것(나무, 꽃, 바위)은 가방·버튼·놓을 자리 미리보기 모두 **맵에 있는 모양 그대로** 보인다. 줍는 🪨 돌과 놓는 바위는 다른 것
   - **놓기**: 공격 버튼 위 작은 동그라미에서 나무 / 꽃 / 바위를 골라 들고 ✋. 내 칸 기준으로 바라보는 쪽 → 양옆 → 뒤 순서로 놓을 수 있는 첫 칸에 초록 테두리가 보이고, 거기에 놓는다 (4방향이 다 막혔으면 빨강, 못 놓음)
     - 풀밭/모래에만. 아이템이 있는 곳, 집 앞 길에는 못 놓는다
     - 나무 / 바위 / 벽돌 / 문 / 횃불은 다른 사람/몬스터가 서 있는 칸에는 못 놓는다
   - **짓는 블록**은 집 제작대에서 만든다 (아래 제작 표). 놓은 블록은 다시 캐서 돌려받을 수 있다
     - 🧱 벽돌: 길을 막는 벽 (집 짓기)
     - 🚪 문: 사람은 지나가고 **몬스터는 못 지나간다** (내 집 입구)
     - 🌉 다리: **물 위에만** 놓는다. 물을 건너갈 수 있다 (캐면 다시 물)
     - 🔥 횃불: 둘레 3칸에 **몬스터가 못 들어온다** (작은 안전지대). 🍄 어두운 늪에서는 둘레를 주황빛으로 밝힌다
     - 가시 울타리: 사람도 몬스터도 못 지나간다. 붙은 사나운 동물(육식동물, 보스)은 1.5초마다 따끔 (체력 -1, 단어 카드 없음)
2. 집(🏠)에 들어가면 체력이 다 차고, 제작대에서 무기를 만든다
3. 몬스터를 물리치면 **단어 카드** → 읽으면 계속. 몬스터가 재료를 떨어뜨리고, 새 무기 레시피가 열린다
4. 몬스터를 3마리 잡으면 보스가 나타난다 (화면 가장자리 🐉 화살표를 따라가기)
5. 보스를 물리치면 다른 몬스터처럼 단어 카드 한 장 → 같은 맵에서 계속 (몬스터는 계속 나오고, 3마리 더 잡으면 용이 다시 등장)
   - 용은 늘 돌아다니고, 7칸 안에 들어오면 쫓아온다

- 체력(❤️)이 0이 되면 "기절!" → 집에서 다시 시작 + 단어 카드. 아이템은 잃지 않는다
- 집 주변은 몬스터가 들어오지 못하는 안전지대
- 다쳤을 때 음식을 주우면 바로 먹고, 체력이 1 남으면 가진 음식을 자동으로 먹는다
- 체력이 가득일 때 주운 ❤️ 는 가방에 들어가고, 체력이 1 남으면 자동으로 먹는다
- 맞으면 빨갛게 번쩍이며 뒤로 살짝 밀린다
- 주운 재료/음식(6초), 하트(10초), 잡은 몬스터(8초)는 시간이 지나면 맵 다른 곳에 다시 생긴다 (몬스터가 떨어뜨린 재료는 다시 생기지 않음)
- 시작 화면의 🎨 로 주인공 모양(옷 색, 모자)을 고를 수 있다. 고른 모양은 기기에 저장된다

## 원격 여럿이 하기 (👥)

여러 기기(2명, 4명, 그 이상)가 **같은 맵**에서 만나 함께 놉니다. 인터넷이 필요합니다. 모두 **같은 규칙**입니다.
몬스터, 아이템, **캐고 놓은 맵**이 모두에게 똑같이 보입니다 (같이 숲을 정리하고 꾸미기). 나중에 들어온 사람도 그때까지 바뀐 맵을 그대로 받습니다.

**지금은 모두 1111 방 하나에서 논다** (`game.js` 의 `ONE_ROOM`). 이름을 넣고 **▶ 만 누르면** 된다.
- 테스트할 때는 주소에 `?room=9876` 처럼 다른 번호를 붙이면 그 방으로 간다 (노는 사람들 방에 섞이지 않게)
- **방장 없음, 서버가 채널을 돌린다**: 이 컴퓨터에서 `server\start-server.bat` 을 켜 두면 채널(1111)의 세상(동물, 아이템, 보스, 바뀐 칸)을 서버가 돌린다. 사람 기기는 모두 손님이다. 자세한 건 [server/README.md](server/README.md)
  - 게임 파일이 새 버전으로 바뀌면(`index.html` 의 `game.js?v=` 숫자가 커지면) 서버가 30초 안에 알아서 새로 켜진다 (세상은 방에 남아 있어서 그대로). 서버가 예전 버전이어도 사람 기기는 모르는 아이템을 빼고 그린다
- **채널마다 세상이 하나**: 바뀐 맵 칸과 보스 진행은 Firebase `rooms/{채널}/t`, `world` 에 남는다. 서버를 껐다 켜도, 아무도 없어도 그대로. 세상이 없는 채널은 채널 기본 맵으로 새로 만든다
- 서버가 꺼져 있으면 ▶ 를 눌러도 "🖥️ 서버가 켜지길 기다리는 중…" 으로 기다리다가, 켜지면 바로 들어간다. 놀다가 서버가 꺼지면 📴, 다시 켜지면 📶 로 이어진다
- 인터넷이 안 되면 혼자 논다 (📴)
- 시작 화면의 👥, 🏠 방 만들기, 번호 칸, 참가 ▶ 는 회색으로 남겨 두었고 누를 수 없다. `ONE_ROOM` 을 `null` 로 바꾸면 아래 예전 방식으로 돌아간다

예전 방식 (방 번호 고르기):
1. 모든 기기에서 시작 화면에서 이름을 입력
2. **한 기기**: 👥 → 🏠 → 화면 왼쪽 위에 4자리 방 번호가 나온다
3. **다른 기기들**: 👥 → 방 번호 입력 → ▶ (또는 주소 뒤에 `?join=1234` 를 붙여 열면 번호가 미리 채워짐)

- 각자 체력(❤️ 5), 가방, 무기, 제작, 단어 카드를 따로 가진다. 아이템은 먼저 주운 사람 것
- 어디서든 서로 때릴 수 있다 (집 앞도). 한 번 맞으면 하트 1개, 하트가 0이 되면 기절 → 집에서 다시 시작 + 단어 카드, 쓰러뜨린 사람도 단어 카드
- 기절 후 다시 시작하면 3초 동안은 맞지 않는다. 집 주변 안전지대는 몬스터만 못 들어온다
- 모든 사람 머리 위에 남은 하트가 작게 보인다
- 같은 칸을 두 사람이 동시에 캐거나 놓으면 먼저 한 사람만 된다
- 몬스터는 가까운 사람을 쫓는다. 몬스터를 잡은 사람이 단어 카드를 읽고 무기 레시피가 열린다. 용은 모두가 잡은 1탄 동물 수를 합쳐서 나온다
- 다른 사람이 카드/제작/기절 중이면 머리 위에 📖 🔨 💫 가 보이고, 그동안은 몬스터도 쫓지 않고 맞지도 않는다
- 내 이름은 파란색, 다른 사람 이름은 빨간색. 화면 밖에 있으면 가장자리에 🧑 화살표와 이름이 나온다
- **새로고침해도 그대로**: 여럿이 하던 탭을 새로고침하면(새 버전 배포 등) 시작 화면 없이 바로 이어진다. 방장은 같은 번호로 방을 다시 열고 (옛 방이 아직 남아 있으면 이 기기 방인지 확인하고 최대 3초 기다렸다가 같은 번호로), 들어와 있던 사람은 그 방이 다시 열릴 때까지 ⏳ 기다렸다가 들어간다 (새로고침 안 해도 📴 → 📶 로 저절로 다시 이어짐)
  - 소리는 브라우저 규칙 때문에 새로고침 뒤 첫 키/터치부터 난다
  - 창을 닫았다 새로 열면 시작 화면이 나온다 (지난번 방 번호는 채워져 있다)
- 놀다가 왼쪽 위 **🏠** (방 번호 옆): "처음 화면으로 갈까요?" ✅ 를 누르면 저장하고 방에서 나가 이름 입력 화면으로 (❌ / Esc 는 계속 놀기)
- **🤝 놀아주기** (왼쪽 위, 방 번호 옆): 켜면 내 캐릭터가 저절로 가장 가까운 다른 사람(아이) 곁에서 논다. 다시 누르면 끈다
  - **아이 지키기**: 아이를 노리는 몬스터가 오면 🛡️ 를 띄우고 아이와 몬스터 사이로 끼어들어 막고 싸운다 (잡으면 카드 없이 👍). 아이가 맞으면 😠 하고 바로 달려간다
  - 사람처럼 싸운다: 휘두르는 사이에 틈이 있고, 맞으면 잠깐 물러섰다가 다시 간다. 하트가 2개 이하(용은 3개)면 😱 도망쳤다가 아이 곁에서 지켜본다. 그래도 아이 바로 옆까지 오면 싸운다
  - 몬스터에게 물리고 다른 사람 칼에 맞는 것은 보통 때와 똑같다 (하트가 다 닳으면 기절해서 집에서 다시 시작, 단어 카드만 건너뛴다)
  - **짓기**: 아이에게서 3~8칸 떨어진 빈 풀밭에 🏠 집 → 💚 하트숲 → 🌀 미로 → 🏰 성 → 😊 웃는 얼굴 → 🌸 꽃밭을 차례로 짓는다 (하나 다 지으면 🎉, 25~45초 쉬었다가 다음 것. 3탄 미로 안에서는 길을 막지 않게 짓지 않는다). 재료는 둘레의 나무/바위/꽃을 몇 개씩 캐 와서 한꺼번에 놓는다 (사람이 놓은 블록은 캐지 않는다)
    - 집: 바위(없으면 벽돌, 나무) 벽 + 문(가방에 🚪 있으면) + 드나드는 틈, 안에 꽃
    - 하트숲: 나무로 하트 모양, 안에 꽃. 아래 끝이 열려 있어 들어갈 수 있다
    - 미로: 7×7, 위 왼쪽으로 들어가 아래 오른쪽으로 나온다
    - 성: 뾰족뾰족한 탑 + 가운데 문, 안에 꽃
    - 웃는 얼굴: 나무 동그라미 안에 꽃으로 눈과 웃는 입
    - 꽃밭: 꽃 동그라미, 가운데 나무 한 그루
    - 아이가 서 있는 칸은 비켜서 나중에 다시 놓는다
  - **양보**: 떨어진 아이템(하트, 먹이 포함)은 절대 줍지 않는다. 아이 둘레에 떨어진 것이 있으면 그 옆에 가서 아이를 보며 👉 (말풍선 "여기 있어! 주워 봐!")
  - **누구랑**: 🤝 를 누르면 "누구랑 놀아줄까요?" 가 나오고 **지율**이 처음부터 골라져 있다 (✅ / Enter 한 번). 방에 있는 다른 사람도 고를 수 있다. 고른 사람만 따라다니고, 아직 안 들어왔으면 (💤) 들어올 때까지 켠 곳 둘레에서 논다. 버튼에 고른 이름이 보인다
  - **하트**: 아이가 다치면 (하트 3개 이하) 내 가방의 물약(없으면 먹이)을 아이 발밑에 갖다 준다 ("이거 먹고 힘내!"). 나는 하트가 2개 이하일 때만 내 가방 것을 먹는다
  - **말풍선**: 하는 일마다 짧게 말한다 ("내가 지켜줄게!", "집 지어 줄게!", "잡았다!" 등). 아이 기기에서 소리로 읽어 준다 (같은 말은 한동안 다시 하지 않는다)
  - **아이 따라 하기**: 아이가 카드를 끝내면 "잘했어!", 동물을 꼬시면 "우와! 귀엽다!", 몬스터를 잡으면 "최고야!" 하며 곁에 와서 콩콩. 나무/바위를 캐면 "같이 캐자!" 하고 곁의 같은 것을 캐 주고, 블록을 놓으면 "나도 놓을래!" 하고 그 옆에 이어서 놓는다
  - **술래잡기**: 아이가 때리면 "아야! 잡아 봐라~" 하고 3~5칸 둘레로 도망 다닌다. 또 맞으면 "잡혔다! 이번엔 내가 잡는다!" 하고 쫓아가서 닿으면 "잡았다!" (때리지 않는다)
  - **🧭 미로 길 안내**: 아이가 3탄 절벽 미로 안에 있으면 "따라와! 길 알려 줄게" 하고 앞장선다. 아이 자리에서 🎁 보물 상자까지 길을 찾아 아이보다 4칸쯤 앞에 서고, 너무 떨어지면 멈춰서 아이를 보며 "따라와!" / "이쪽이야!" 하고 부른다 (아이가 막다른 길로 가도 맞는 길 쪽에서 부른다). 상자 가까이 오면 "보물 상자다! 열어 봐!" (상자는 아이가 연다), 그 뒤 1분은 혼자 해 보게 안내하지 않는다. 몬스터가 오면 먼저 지킨다
  - **숨바꼭질**: 지어 둔 미로가 아이 가까이 있으면 가끔 "숨바꼭질 하자!" 하고 미로 안쪽에 숨는다. 아이가 오면 "찾았다!", 45초 지나면 "여기 있지롱!"
  - **선물**: 꼬신 동물을 아이에게 준다 (아이 동물이 3마리보다 적을 때, 아이 화면에 "🎁 ○○를 선물 받았어요!"). 먹이가 3개 이상, 꽃이 6개 이상이면 하나씩 아이 발밑에 놓아 준다
  - **사람처럼**: 따라다니다 가끔 두리번거리고 콩 뛰고, 휘두르다 가끔 헛손질
  - 먹이가 있으면 초식동물을 꼬시고 (던진 먹이가 동물 쪽으로 휜다), 꽃을 캐서 아이 둘레 2~3칸에 심고 (늪에서는 횃불), 사이사이 아이 곁을 서성이며 😊 👋 🎵
  - 내 공격은 다른 사람에게 절대 맞지 않는다. 키/조이스틱을 쓰면 그동안은 직접 움직이고, 손을 떼면 다시 저절로. 집 문에 닿아도 제작대가 열리지 않는다
  - 머리 위 그림(💪 👍 😊)은 다른 사람 화면에도 보인다. 혼자일 때는 켠 자리 둘레에서 논다
- 방을 만든 기기가 아이템/몬스터를 돌린다. 그 기기 창을 닫으면 방이 사라진다. 혼자 할 때(▶)는 Firebase 에 전혀 접속하지 않는다

### Firebase 설정 (처음 한 번)

통신은 Firebase Realtime Database(무료 Spark 플랜)를 씁니다. 설정값은 `net.js` 에 있습니다 (브라우저에 공개되도록 만들어진 값이라 비밀이 아님).

1. Firebase 콘솔에서 프로젝트 생성 → 웹 앱 추가 → 나온 `firebaseConfig` 를 `net.js` 에 붙여넣기
2. **Authentication → 로그인 방법 → 익명** 사용 설정
3. **Realtime Database** 생성 후 **규칙**에 다음을 게시:

```json
{ "rules": {
  "rooms": { "$room": {
    ".read": "auth != null && $room.matches(/^[0-9]{4}$/)",
    ".write": "auth != null && $room.matches(/^[0-9]{4}$/)" } },
  "bags": { "$name": {
    ".read": "auth != null && $name.length <= 16",
    ".write": "auth != null && $name.length <= 16" } } } }
```

`bags` 는 캐릭터 이름별 가방입니다. 이 규칙이 없으면 가방은 서버에 저장되지 않고 이 기기에만 저장됩니다 (게임은 그대로 됨).

## 실행 방법 (로컬)

마이크는 **https 또는 localhost** 에서만 동작합니다.
`index.html` 을 더블클릭해서 여는 방식(`file://`)은 **지원하지 않습니다.**

```bash
# 레포 폴더에서
python -m http.server 8000
```

Chrome 에서 <http://localhost:8000> 을 엽니다. ▶ 를 누르면 마이크 권한을 물어보는데, **허용**해 주세요.

### 테스트용 URL 옵션 (부모 설정 화면이 생기기 전 임시)

| 옵션 | 값 | 예시 |
|---|---|---|
| `lang` | `ko`, `en`, `both` (지금 words.csv 에는 한국어 단어만 있어서 `en` 이어도 한국어 카드가 나온다) | `?lang=ko` |
| `level` | `1`~`3` (누적: 2 → level 1~2) | `?level=1` |
| `strict` | `loose`, `normal`, `strict` | `?strict=loose` |
| `stt` | `0` 이면 음성 인식 끔 (탭 모드) | `?stt=0` |

옵션은 그 주소로 연 이번 실행에만 적용되고 저장되지 않습니다. 기본값은 `lang=ko`, `level=2`, `strict=normal` 입니다.

### 태블릿에서 테스트하기

같은 와이파이에서 `http://PC의IP:8000` 으로 접속하면 게임은 열리지만, **https 가 아니어서 마이크가 동작하지 않고** 자동으로 탭 모드가 됩니다. 마이크까지 테스트하려면 다음 중 하나를 쓰세요.

1. **USB + adb 포트 전달 (추천)**: 태블릿에서 개발자 옵션 → USB 디버깅을 켜고 PC와 연결한 뒤
   ```bash
   adb reverse tcp:8000 tcp:8000
   ```
   태블릿 Chrome 에서 `http://localhost:8000` 을 엽니다.
2. **GitHub Pages 에 올려서 https 로 접속** (아래 배포 방법 참고)

## 그림 해상도 (v85)

화면의 모든 픽셀이 같은 크기입니다: **그림 1칸 = 1 월드 px** (맵 칸 하나 = 32 월드 px).

- 세상(맵, 캐릭터, 몬스터, 아이템, 텐트/대장간, 화살, 휘두르기)은 "1 월드 px = 1 픽셀" 인 작은 캔버스에 먼저 그리고 화면 크기로 키운다 (`Render.draw` → `drawWorld`). 그래서 무엇을 그려도 픽셀 크기가 같다
- 글자(이름표, 말풍선, 하트)와 이모지 표시(🔨, 📖)는 `Render.later` 로 미뤄서 화면 해상도로 또렷하게 그린다
- 화면에서 그림 1칸은 노트북에서 약 3px, 태블릿에서 약 3~5px (`VIEW_TILES: 9`: 화면 짧은 변에 9칸)

| 그림 | 크기 (칸) | 그리는 방법 |
|---|---|---|
| 맵 칸 (풀, 나무, 바위, 물, 모래, 길, 절벽, 블록) | 32×32 | `World.drawTile` 이 코드로 그린다. 위 왼쪽이 밝고 아래 오른쪽이 어둡고, 칸마다 hash 로 무늬가 조금씩 다르다 |
| 집 | 96×96 | `World.drawHouse` (판자, 기와, 창문, 문) |
| 캐릭터 | 20×32 | `Render.drawCharacter` (옆모습은 왼쪽 보기를 거울로). 모자는 `drawHat` |
| 몬스터 | 크기 그대로 (토끼 22, 용 56) + 테두리 1 | `PixelSprite`: 이모지를 작게 줄여 색을 단순하게 하고 까만 테두리 |
| 아이템 (재료, 음식, 물약, 무기, 옷, 블록) | 24×24 (손에 든 것, 던진 먹이 16×16) | `ICON_ART`: 24칸 기준 좌표(사각형, 타원, 선, 다각형 + 명암)로 그리고, 그 크기의 픽셀마다 다시 계산한다 (늘린 그림이 아니다). 블록 아이템은 `BLOCK_` 그림. 테두리 1칸 |

## 제작

제작대는 탄마다 하나씩, 모양이 다릅니다. 레시피는 모두 같습니다.

- 1탄: 🏠 **집 안** (들어가면 하트도 가득)
- 2탄: ⛺ **클로버 텐트** (들판 가운데 길 옆, 초록/하양 줄무늬, 꼭대기에 깃발)
- 3탄: ⚒️ **대장간** (미로 입구 방 왼쪽 위 구석, 돌 화덕에 불이 일렁이고 굴뚝 연기. 불빛이 어두운 미로를 밝힌다)

텐트와 대장간은 몸이 닿으면 제작대가 열립니다 (한 번 열면 떨어졌다가 다시 와야 또 열린다). 위에 🔨 가 떠 있고, 화면 가장자리 화살표와 작은 지도에 ⛺ / ⚒️ 로 보입니다.

### 아이템 체계 (v79, 가방 판 BAG_V 2: 예전 가방은 비우고 새로 시작)

모든 아이템은 이모지 대신 픽셀 그림(블록은 맵 칸 그림)으로 보입니다 (그림 크기는 아래 **그림 해상도** 참고). 종류는 다섯 가지입니다.

| 종류 | 하는 일 | 아이템 |
|---|---|---|
| 🪵 재료 | 제작대에서만 쓴다 | 통나무, 돌, 실, 가죽, 가시, 네잎클로버(2탄), 보석(3탄) |
| 🧱 블록 | 땅에 놓는다 | 꽃, 🌱 묘목, 벽돌, 문, 다리, 횃불, 가시 울타리 |
| 🍎 음식 | 먹으면 ❤️, 던지면 좋아하는 동물이 따라온다 | 사과 ❤️1, 당근 ❤️1, 고기 ❤️2, 생선 ❤️2, 꿀 ❤️1, 🎂 케이크 ❤️5 |
| ⚗️ 물약 | 마시면 특별한 힘 | 빨강 ❤️+3 / 파랑 🏃 30초 1.5배 빨리 / 노랑 💡 60초 어두운 늪·미로가 밝다 |
| 🛡️ 장비 | 무기는 손에, 옷은 몸에 (꾸미기), 방패는 가방에 | 도끼, 활, 칼 / 가죽 모자, 👑 왕관, 가죽 갑옷, 장화 / 방패 |

- **캐면 언제나 재료**: 나무 → 통나무 2 + 🌱 묘목 1, 바위 → 돌 2. 꽃은 그대로 꽃 블록. (나무 → 통나무 같은 조합은 없앰)
- **🌱 묘목**: 땅에 심으면 30초쯤 뒤 나무로 자란다 (방장/혼자 기기가 5초마다 1/6 확률로 키움). 심은 묘목은 막는 칸, 손으로 캐면 묘목이 돌아온다.
- **❤️ 하트**: 가방에 넣지 않는다. 다쳤을 때만 주워서 바로 체력을 채운다.
- 맵에 저절로 떨어져 있는 것: 통나무, 돌, 실, 사과, 당근.
- 제작대에서 **아직 한 번도 얻지 못한 재료**가 들어가는 것은 까만 그림자 + `???` 로, 그 재료 자리는 ❓ 로 보인다 (찾으러 가게).

**동물마다 좋아하는 음식**: 좋아하는 음식(또는 🎂 케이크)을 맞으면 💕 따라온다. 다른 음식은 🙅 고개를 젓고 먹이는 그 자리에 떨어지며, "토끼는 당근을 좋아해요" 하고 말해 준다.

| 동물 | 좋아하는 음식 |
|---|---|
| 🐰 토끼, 🐇 클로버 토끼, 🐔 닭, 🐌 달팽이 | 🥕 당근 |

무기, 방패, 옷은 한 번만, 블록, 음식, 물약은 몇 번이든 만들 수 있습니다. 새로 만들 수 있는 무기(방패)나 옷이 있으면 집/텐트/대장간 위에 🔨 가 통통 튑니다.

**옷** (만들었을 때 그 곳이 비어 있으면 바로 입는다): 입는 곳은 머리 / 몸통 / 다리. 캐릭터 그림과 다른 사람 화면에 보이고, 힘은 없다 (꾸미기).

새로 만든 무기를 바로 듭니다 (주머니 1번 칸에서 바꿀 수 있음). 맨손은 힘 ⭐ 하나입니다.

## 지도와 동물

집은 지도 한가운데에 있고, 지도는 네 구역으로 나뉩니다. 경계는 구불구불하게 이어지고, 집에서 구역마다 숲길이 나 있습니다. 작은 지도에 구역 그림(🌲 🏞️ 🍄 🌼)이 보이고, 구역에 들어서면 이름이 잠깐 뜹니다. 동물은 자기 구역에서 생기고, 쫓아가지 않을 때는 그 구역 안을 돌아다닙니다.

| 구역 | 땅 | 동물 (체력 / 떨어뜨리는 것) |
|---|---|---|
| 🌲 무서운 숲 (왼쪽 위) | 나무가 빽빽 | **육식동물**: 🐺 늑대 4 / 🥩 가죽, 🦊 여우 4 / 🥩 가죽, 🐻 곰 6 / 🥩🥩 가죽, 🐯 호랑이 7 / 🥩🥩 가죽 2 |
| 🏞️ 호수 (오른쪽 위) | 큰 호수가 많다 (🌉 다리로 건너기) | 🐟 물고기 2 / 🐟 생선, 🐡 복어 3 / 가시 (물속에서만, 다가가면 도망), 🦛 하마 5 / 🥩🥩 가죽, 🦀 게 3 / 🐟 생선 |
| 🍄 어두운 늪 (왼쪽 아래) | 어둡고 축축 (화면이 어두워지고 내 둘레만 밝다), 웅덩이와 바위가 많다 | 🕷️ 거미 3 / 🧵🧵, 🦂 전갈 4 / 가시 (육식), 🐜 개미 2 / 🥚, 🦇 박쥐 2 / 가죽 |
| 🌼 초원 (오른쪽 아래) | 꽃밭 | **초식동물**: 🐰 토끼 2 / 🥩, 🐑 양 3 / 🧵🧵 (털), 🐄 소 4 / 🥛🥛 가죽, 🐔 닭 2 / 🥚🥚, 🐖 돼지 3 / 🥩🥩, 🦌 사슴 3 / 🥩 가죽 |

🐉 용 (보스, 체력 12)은 1탄 동물을 3마리 잡을 때마다 1탄에서 집과 가장 먼 곳에 나타나고 1탄 안을 돌아다닙니다.

- **초식동물 / 물고기**: 먼저 공격하지 않고, 사람이나 육식동물이 다가오면 도망간다. 잡으면 몬스터처럼 재료가 나오고 단어 카드
- **먹이 주기**: 그 동물이 좋아하는 음식(🥕 / 🍎, 🎂 케이크는 모두)을 손에 들고(주머니 3번 칸) ✋ 를 누르면 앞으로 던진다. 초식동물이 맞으면 💕 그 사람을 계속 따라다닌다 (체력 막대가 초록, 작은 지도에 분홍 점). 못 맞히면 떨어진 자리에 놓여서 다시 주울 수 있다
- 따라다니는 동물은 주인 둘레에 저마다 자리를 잡고 서성이며 논다 (겹치지 않게 비켜 서고, 가끔 콩 뛰며 💕 🎵 ✨). 주인이 멀어지면 서둘러 따라온다
- 내 동물에게 먹이를 또 던져 주면 😍 좋아하며 콩콩 뛰고 체력이 다 찬다
- 따라다니는 동물은 내 공격에 맞지 않는다. 멀리 떨어지면 (기절해서 집에서 다시 시작 등) 내 옆으로 온다. 저장되어 다음에도 집 앞에서 따라온다
- **육식동물**(숲 동물, 거미, 전갈)은 사람뿐 아니라 초식동물도 쫓아가서 문다. **따라다니던 동물도 물려서 쓰러질 수 있다** (💔). 집 앞 안전지대와 🔥 횃불 둘레에는 육식동물이 못 들어와서 거기 있으면 안전하다
- 잡힌 동물은 8초 뒤 자기 구역에 다시 생긴다

### 📝 문장 카드 (1분마다)

- 놀고 있는 시간(카드/제작대/기절 시간은 빼고)이 1분 지나면 "계속하려면 문장을 읽어 봐요!" 하고 문장 카드가 나온다. 읽는 방법, 틀렸을 때 🔊 / 따라 읽기는 단어 카드와 같다
- 문장은 게임과 상관없는 한글 공부 문장. 띄어쓰기 빼고 8글자까지 (`SENTENCE_MAX`)
  - 정해 둔 문장 (`SENTENCE_FIXED`, 예: "엄마 아빠 사랑해요", "손을 씻어요") 반, 낱말 조각을 맞춘 문장 (`SENTENCE_PARTS`, 예: "할머니 고마워요", "토끼가 하품해요") 반. 최근 20개는 다시 안 나온다
  - 영어(🇺🇸)로 놀면 짧은 영어 문장
- 이벤트 단어 카드(몬스터, 기절, 네잎클로버)를 읽으면 1분을 처음부터 다시 센다
- 📖 단어 OFF, 🤝 놀아주기 중에는 나오지 않는다. 시간은 `CONFIG.SENTENCE_EVERY_SEC`

몬스터를 물리치면 그 몬스터와 **같은 이모지**의 단어가 `words.csv` 에 있을 때 그 단어 카드가 나옵니다 (예: 🦊 → "여우"). 없으면 다른 단어가 나옵니다.

레시피는 `game.js` 의 `RECIPES`, 무기는 `WEAPONS`, 몬스터는 `MONSTERS` / `BOSS`, 난이도(체력, 보스 등장 조건 등)는 `CONFIG` 에서 바꿀 수 있습니다.

## 탄(스테이지)

맵은 1탄·2탄이 120×90 칸씩 옆으로 이어지고 (`CONFIG.STAGE_W`, `MAP_W` 240), 3탄은 2탄 아래에 붙는다 (`STAGE_H` 90, `MAP_H` 150). 칸 번호는 y × 240 + x 라서 맵이 아래로 길어져도 1탄·2탄의 바뀐 칸은 그대로다. 작은 지도에는 내가 있는 탄만 보인다 (2탄은 왼쪽, 3탄은 위 테두리 나무까지 보여서 네 테두리가 다 보인다). 누르면 화면 가운데에 크게 보인다. 다음 탄 가는 나무는 작은 지도에 🔒 (잠김) / ✨ (황금 나무) 로 보인다.

- **탄마다 동물은 따로**: 야생 동물과 보스는 다른 탄으로 넘어가지 않는다 (따라다니는 내 동물만 같이 간다). 보스 화살표, 작은 지도의 보스 점, 보스 등장 알림은 그 탄에 있는 사람에게만 보인다
1탄은 예전 맵 그대로라서 저장해 둔 바뀐 칸(지은 집 등)도 그대로다 (예전 넓이로 저장한 칸 번호는 불러올 때 맞춘다).

- **탄 사이 문**: 1탄 오른쪽 테두리 가운데쯤 나무 하나가 처음부터 ✨ **황금 나무**다 (보스를 안 잡아도 된다. 화면 가장자리에 ✨🌳 화살표). 캐면 (맨손 3번 / 🪓 1번, 나오는 것 없음) 2탄 길이 열린다. 탄 사이 다른 테두리 나무는 캘 수 없다
- **2탄 🍀 클로버 들판**: 들판 곳곳 클로버밭. 대부분 세잎클로버(하트 잎 3개 + 아래로 줄기)이고 그 사이에 **네잎클로버**(크기와 색은 똑같고 잎만 4개)가 16개 숨어 있다. 바라보고 ✋ 한 번이면 뽑혀서 가방에 🍀 + "클로버" 단어 카드, 그 자리는 세잎클로버가 된다
  - 🐇 **토끼**는 네잎클로버를 찾아가서 한 잎 먹는다 (😋, 세잎클로버가 된다). 토끼보다 먼저 찾아야 한다. 먹이를 주면 따라다니며 내 둘레 네잎클로버 위에 앉아 🍀 로 알려 준다
  - 뽑히거나 먹힌 만큼 다른 클로버밭에 (사람이 안 보는 곳에) 다시 난다
  - 동물: 🐇 토끼 / 🥩, 🐌 달팽이 / 🥚 (꼬실 수 있음), 🦔 고슴도치 / 가시 2, 🐍 뱀 / 가죽 (쫓아옴), 🐝 벌 / 🍯 꿀. 2탄이 열린 뒤에 생긴다
  - 보스: 모두 합쳐 네잎클로버를 4개 찾을 때마다 🦅 **독수리**. 잡으면 "2탄 클리어!"
  - 🤝 놀아주기는 아이 곁의 네잎클로버를 찾아 옆에 가서 👉 "여기 네잎클로버!" (뽑는 건 아이가)
- 2탄 아래 테두리 가운데에 ✨ 황금 나무가 있고 (처음부터 캘 수 있다) 들판 가운데에서 거기까지 길이 나 있다. 캐면 3탄 길이 열린다
- **3탄 🧭 절벽 미로** (2탄 아래 120×60 칸): 캘 수 없는 절벽 벽 사이 3칸 너비 길 (방 29×15). 입구는 황금 나무 바로 아래, 맨 끝 방에 🎁 **보물 상자**
  - 고리가 없는 미로라서 **오른쪽 벽을 손으로 짚고 따라가면 언젠가는** 보물 상자에 닿는다 (멀리 돈다). 갈림길과 짧은 막다른 길이 많아서 아이는 헤맬 수 있다
  - 🗺️ 작은 지도를 누르면 미로 전체가 크게 보이고, 지나온 길이 하늘색 발자국으로 남는다 (보물 🎁 / 입구 ✨ 도 보인다). 지도를 보며 길을 찾는 연습
  - 보물 상자 옆에 가면 "미로 탈출!" 축하 + 💎 보석, 3.5초 뒤 미로 입구로 돌아오고 발자국도 지워진다 (다시 해 볼 수 있다)
  - 미로 괴물: 👻 **유령** / 실 (반투명하게 둥실둥실, 쫓아옴), 🐀 **쥐** / 🧀 치즈 (빠르고 약함, 쫓아옴), 🦎 **도마뱀** / 가죽 (돌아다님). 3탄이 열린 뒤에 생기고 미로 밖으로 나가지 않는다. 단어 카드: 유령, 쥐, 도마뱀
  - 아이템도 생긴다. 미로 괴물은 1탄 용 등장 수에 들어가지 않는다
  - 미로는 🍄 늪처럼 **어둡다**: 내 둘레와 🔥 횃불 둘레만 밝다 (횃불을 놓으면 길을 밝힐 수 있다)

## 단어 카드 규칙

- **소리 나는 대로 비교**: 글자는 달라도 한국어로 소리가 같으면 맞은 것으로 본다 (게=개=계, 닭=닥, 복어=보거, 돼지=되지, 늑대=늑때). 받침 대표음, 연음, ㅎ 탈락/거센소리, 비음화, 유음화, 된소리, 구개음화, ㅐ/ㅔ·ㅚ/ㅙ/ㅞ·자음 뒤 ㅖ→ㅔ·ㅢ→ㅣ 를 따른다
- 한 글자 단어는 예사소리/된소리/거센소리도 같게 본다 (게=께=케, 소=쏘)

1. 카드가 뜨면 바로 읽어주지 **않습니다.** 아이가 먼저 읽어봅니다. (🎤 이 빨갛게 깜빡이면 듣는 중)
2. 5초 동안 시도가 없거나 한 번 틀리면 🔊 가 반짝입니다. 누르면 게임이 읽어줍니다.
3. 3번 틀리면 게임이 읽어주고 **"따라 읽어봐!"** 모드가 됩니다. 소리를 내거나 ✅ 를 누르면 통과합니다.
4. 마이크 권한 거부, 미지원, 인식 오류 시 자동으로 **탭 모드**(✅ 누르면 통과)로 바뀝니다.
5. 게임이 말하는 동안에는 마이크를 끄고, 끝나면 다시 켭니다.
6. 맞추면 게임이 "단어! 잘했어요" 라고 말합니다. 이때 아무 곳이나(아무 키나) 누르면 말을 끊고 바로 게임으로 돌아갑니다.

판정은 관대하게 합니다. 인식 후보 5개를 모두 보고, 공백/구두점/대소문자를 무시합니다. 한글은 자모 단위로 비슷한 정도를 계산합니다(나무 ≈ 나모). 한 글자 단어는 후보 안에 그 글자가 들어있기만 하면 인정합니다(칼 → "칼이야").
기준값은 `game.js` 맨 위 `CONFIG.JUDGE_THRESHOLDS` 에서 조절합니다.

### 판정 로그 보기

Chrome 개발자 도구(F12) → Console 에서 다음처럼 확인할 수 있습니다.

```
[Judge] 목표="나무" 후보=["나모","나무"] → 최고="나무" 점수=1.00 기준=0.65 (exact) ✅ 통과
```

콘솔에서 판정을 직접 시험해 볼 수도 있습니다: `BC.Judge.judge('나무', ['나모'])`

## words.csv 작성법

단어 카드는 `words.csv` 에서 읽어옵니다. **코드를 고치지 않고 이 파일만 바꾸면 됩니다.**

```csv
id,word,lang,emoji,level,category,alts
ko01,나무,ko,🪵,1,재료,
en07,bee,en,🐝,1,몬스터,be|b
```

| 컬럼 | 필수 | 설명 |
|---|---|---|
| `id` | 권장 | 고유 이름 (학습 기록이 이 값으로 저장됨). 비우면 `lang-word` 로 자동 생성 |
| `word` | ✅ | 카드에 크게 나올 글자 |
| `lang` | ✅ | `ko` 또는 `en` |
| `emoji` | 권장 | 정답을 맞힌 뒤 보여줄 그림 |
| `level` | 권장 | `1`~`3`. 한글 1 = 받침 없음, 2 = 쉬운 받침, 3 = 어려운 단어 |
| `category` | 선택 | 재료, 무기, 몬스터, 음식 등 (분류용) |
| `alts` | 선택 | 음성 인식이 다르게 알아들어도 인정할 말, `\|` 로 구분 (예: bee → `be\|b`) |

- 몬스터와 같은 이모지의 단어가 있으면 그 몬스터를 잡았을 때 그 단어 카드가 우선 나옵니다.
- **엑셀에서 저장할 때는 "CSV UTF-8(쉼표로 분리)"** 형식을 고르세요. 그냥 "CSV" 로 저장하면 한글이 깨질 수 있습니다.
- 줄 첫 칸 제목(헤더)은 지우지 마세요. 컬럼 순서는 바뀌어도 됩니다.

## 개인정보

- 학습 기록(어떤 단어를 어떻게 읽었는지)은 **이 기기의 localStorage 에만** 저장되고, 게임이 외부로 보내지 않습니다.
- 다만 Chrome 의 음성 인식은 **Google 서버에서 처리**됩니다. 마이크 소리가 Google 로 전송된다는 뜻입니다. 원하지 않으면 음성 인식을 끄고(`?stt=0`, 4단계부터는 부모 설정) 탭 모드로 사용하세요. 인터넷이 없을 때도 자동으로 탭 모드가 됩니다.
- 여럿이 하기(👥)를 할 때만 캐릭터 이름과 위치, 몬스터, 바뀐 맵 같은 **게임 상태**가 Firebase 로 오갑니다. 아이 실명 대신 별명을 써도 됩니다. 학습 기록과 음성은 보내지 않습니다.
- **캐릭터 이름과 가방**(아이템, 무기, 잡은 수)은 다른 기기에서 이어서 할 수 있게 Firebase 에 저장됩니다. 실명 대신 별명을 쓰세요.
- 세상(맵) 저장(`bc.world`)은 이 기기에만 저장됩니다. 여럿이 할 때는 바뀐 칸이 방(Firebase)에 올라가 같이 노는 사람에게 보이고, 모두 한 방(1111)에서는 방에 계속 남습니다.
- 이 레포에는 개인정보를 넣지 않습니다. `net.js` 의 Firebase 웹 설정값은 공개용 값이고, 보호는 보안 규칙으로 합니다.

## GitHub Pages 배포

1. 변경 사항을 `main` 브랜치에 push 합니다.
2. GitHub 레포 → **Settings → Pages**
3. **Source: Deploy from a branch**, **Branch: `main` / `(root)`** 를 선택하고 Save
4. 1~2분 뒤 <https://hellohanaworld.github.io/baby_craft/> 에서 열립니다.

모든 파일 경로가 상대 경로라서 `/baby_craft/` 하위 경로에서도 동작합니다.
